方块

方块列表生成

我想要使用贴图来自动生成一系列方块。但是贴图的加载和方块注册的顺序对不上，并且服务端不加载贴图。所以最好使用一种类似配置文件的方法来决定要生成什么方块，因此需要把这部分放到方块列表阶段。

方块列表阶段作为一个独立的模块 gen_block_list，不依赖Minecraft和别的东西。

方块列表阶段需要获取 .\src\main\resources\assets\brfurniture\textures\block 里面有什么方块，然后以 level0_wall 的格式输出到什么地方作为默认的配置文件。同时需要支持在游戏运行时在 config/brfurniture/blocks.txt 覆盖。

具体把默认配置文件存到哪我确实不太知道。如果 NeoForge 没有推荐的实现方案，那直接生成“硬编码”的代码可能还是最好的方案，可以把文件丢到一个和generated平级的code_generated包，而不是generated模块，因为generated模块在运行datagen时会被删除。

按照惯例，如果检测到配置文件缺失需要创建一个默认的配置文件。

加载配置文件和注册时

这部分需要做足防御性编程，加载配置文件是无论如何都不能让游戏崩溃的。

不过需要检查的东西好像也就 ResourceLocation 能不能创建，有没有重名id（包括内部重复和外部冲突）。还有什么东西可以自己补充一下，因为我也不知道。

如果有错误，NeoForge 好像有个警告屏幕可以创建。需要提示哪些东西无法读取，哪些id重名，以及提示删除 config/brfurniture/blocks.txt 可能解决问题。

若当前 NeoForge 版本有可用的警告屏幕 API 则使用；否则写入日志，并在玩家进入世界后通过聊天栏提示一次。不要为了警告屏幕引入不存在的 API。

注册方块

如果拿到一个 level0_wall，就用 brfurniture:block/level0_wall 作为id注册一个实心方块。

同时，在模组主类创建时，可以分别用两个Map来注册 Supplier<Block> 和 BlockBehaviour.Properties。如果没有注册则默认使用 Block::new 和 BlockBehaviour.Properties.of() .instrument(NoteBlockInstrument.BASS) .strength(2.0F, 3.0F) .sound(SoundType.WOOD)

注册的方式应该类似这样：


public class BrFurniture
{
    public BrFurniture(IEventBus modEventBus, ModContainer modContainer)
    {
        putBlock("level0_wall", Block::new);
        putBlock("level0_wall", BlockBehaviour.Properties.of());
    }
}

变种方块

展墙

展墙的代码参考.\example_code\TextureWall.java，注册方面参考.\example_code\BackroomsGeneralBlocks.java。

方块id用brfurniture:exhibition_wall/level0_wall和brfurniture:exhibition_wall_brace/level0_wall

自定义注册应该类似这样：


public class BrFurniture
{
    public BrFurniture(IEventBus modEventBus, ModContainer modContainer)
    {
        putExhibitionWall("level0_wall", Block::new);
        putExhibitionWall("level0_wall", BlockBehaviour.Properties.of());
        putExhibitionWallBrace("level0_wall", Block::new);
        putExhibitionWallBrace("level0_wall", BlockBehaviour.Properties.of());
    }
}

注册好的方块应该打包成类似 "level0_wall": {solidBlock, exhibitionWall, exhibitionWallBrace} 的 Map + List<BlockItem> 结构，方便待会创造物品栏调用。

创造物品栏要把注册好的方块全部送进去，可以参考.\example_code\BackroomsGeneralBlocks.java。

方块的名字需要你来帮我填个硬编码，比如"level0_wall"你就分别填写 "Level0墙壁" 和 "Level0 Wall" 。之后就生成 "Level0墙壁", "Level0展墙", "Level0展墙墙根" 三个项目。

流程

总的流程就是这样的

  1. 前置的贴图资源
  2. 使用 gen_block_list 生成 code_generated
  3. 运行 runData （使用 main 模块，依赖 code_generated 或者 gen_block_list 生成的方块列表）
  4. 运行 build 或 runClient （使用 main 模块，依赖 code_generated 和 runData 产生的资源）

家具

家具一般有自己的特性，比如各种灯具包含点亮和熄灭的逻辑。先写好方块再写家具吧。
